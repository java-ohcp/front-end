# 照片观察与样本分析

页面沿用禾诊的浅色背景、白色面板与绿色控件。打开“样本分析”，使用水分、光照、
土壤三个选项切换指标及历史曲线；键盘也可用左右方向键或 Home / End 切换。

## 照片

诊断页和样本分析页可添加 JPG、PNG、WebP 照片。最多四张，每张不超过 8 MB。
文件通过浏览器解码检查后预览；移除照片、重置表单、切换路由时释放预览资源。
照片不会上传至服务器，当前也没有图像识别接口。请结合照片填写症状描述。
样本分析中切换样本会清空当前照片；照片和测量结果不持久化、不随 JSON 导出。

## 指标字段

| 维度 | 字段 | 单位 |
| --- | --- | --- |
| 水分 | rwc 叶片相对含水量 | % |
| 水分 / 土壤 | soilMoisture 土壤含水率 | %，沿用原仪器定义 |
| 水分 | humidity 空气相对湿度 | % |
| 水分 / 光照 | temperature 环境温度 | ℃ |
| 光照 | lightLux 光照强度 | lx |
| 光照 | ppfd 光合光子通量密度 | μmol/(m²·s) |
| 光照 | sunshineHours 日照时长 | h |
| 土壤 | soilPh 酸碱度 | pH |
| 土壤 | soilEc 电导率 | mS/cm |
| 土壤 | soilTemperature 土壤温度 | ℃ |

缺失数值保留为空，不补成零。RWC 如未提供，仅在鲜重 freshWeight、干重 dryWeight、
饱和鲜重 turgidWeight 均有效时，按 `(鲜重−干重)/(饱和鲜重−干重)×100%` 计算。
三种质量必须使用相同单位，本页按克展示；不会从鲜重和干重两项直接推算 RWC。

## 文件格式

JSON 可用单个对象、对象数组或 `{ "samples": [...] }` / `{ "records": [...] }`。
CSV / TSV 首行为字段名，一行一个样本；支持带引号字段、转义引号和字段内换行。
每次导入会替换当前样本列表，解析失败保留已有样本。

下面是**合成示例**，不代表真实测量结果：

```json
{
  "id": "DEMO-FORMAT",
  "name": "格式示例",
  "crop": "水稻",
  "origin": "demo",
  "rwc": 92,
  "lightLux": 32500,
  "soilMoisture": 34.6,
  "soilPh": 6.5,
  "history": [
    { "time": "08:00", "rwc": 92, "lightLux": 16000, "soilMoisture": 35.2 },
    { "time": "10:00", "rwc": 91, "lightLux": 32500, "soilMoisture": 34.6 }
  ]
}
```

历史数组保持文件顺序。水分趋势读取 rwc，光照趋势读取 lightLux，土壤趋势读取
soilMoisture；每种指标至少两个有效点才绘图。缺失点断开，不插值或预测。
CSV 只导入单次指标；带历史曲线的数据使用 JSON。

## 数据来源与边界

初始样本为明确标注的示例。文件导入仅表示读入文件，不表示验证过来源。
已标记 origin 为 demo 的示例在导出、重新导入后继续保留示例标识。
没有历史数据时不画合成趋势；不从照片计算光照、土壤数据或含水量。
这些记录不自动产生缺素判断、胁迫等级或施肥用量。

本次未增加依赖、后端接口或模型调用。已有诊断接口请求格式保持不变。
